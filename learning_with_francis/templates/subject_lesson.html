{% if subject.slug == 'python' %}

1. Give values a name

A variable name refers to a value. Assignment uses =. Quoted text is a string; a whole number is an integer. True and False are booleans.

name = "Mia"
age = 20
count = 2
count = count + 3
print(count)  # displays 5

The right side of an assignment is evaluated first. The old count is 2; adding 3 and assigning again makes count 5.

2. Put a reusable task in a function

def defines a function. A parameter names an input. Indent the function body, normally with four spaces. Defining a function does not call it.

def add_one(number):
    return number + 1

result = add_one(4)
print(result)  # displays 5

The call supplies 4 as the argument for number. return sends 5 back; the caller stores it in result. print() displays output rather than returning that result for reuse.

{% elif subject.slug == 'javascript' %}

1. Values and variable bindings

JavaScript uses values such as numbers, quoted strings and booleans (true or false). Use let for a binding you will reassign. const prevents reassignment of the binding; it does not freeze an object's properties.

let score = 1;
score = 2;
const greeting = "Hello";
const ready = true;

2. Find an element and react to a click

The DOM is the browser's object representation of HTML. querySelector() finds the first element matching a CSS selector. A # selects an id. A missing match returns null.

<p id="message">Ready</p>
<button id="greet-button">Greet</button>
<script>
const message = document.querySelector("#message");
const button = document.querySelector("#greet-button");
if (message && button) {
    button.addEventListener("click", function () {
        message.textContent = "Hello, learner!";
    });
}
</script>

This example puts the script after its elements. addEventListener() registers a function; it runs when the click happens. textContent changes plain text. This is a code-reading example, not a live editor.

{% elif subject.slug == 'sap' %}

1. Connected business information

ERP means Enterprise Resource Planning. SAP provides ERP software connecting areas such as purchasing, inventory, sales and finance. Sharing information helps departments work from consistent records.

Master data describes reusable entities: a supplier's address, a customer or a material. Transactional data records particular events, such as one purchase order, goods receipt or invoice.

2. A shop orders chairs

  1. Create a purchase order specifying the chairs and quantity requested from a supplier.
  2. When the chairs arrive, record a goods receipt. For this stock example, inventory increases.
  3. Check the supplier's invoice against the order and received goods; investigate differences.
  4. Arrange payment after the appropriate checks.

For a sale, a sales order records what the customer orders; delivery, customer invoicing and payment follow in a simplified example. These are typical learning scenarios, not fixed rules for every SAP installation. Configuration and real workflows vary.

This lesson teaches concepts. It does not connect to SAP, run business transactions or provide professional certification.
