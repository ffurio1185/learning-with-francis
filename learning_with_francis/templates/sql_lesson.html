SQL: SELECT and WHERE

Welcome, {{ visit.display_name }}! SQL helps you read information from tables. A table has columns (kinds of information) and rows (individual records).

Our example: learners

1. Choose columns with SELECT

SELECT says which columns to show. FROM says which table to read. Separate several column names with commas.

SELECT name, city FROM learners;

This returns Alex/Berlin, Mia/Hamburg and Sam/Berlin. It reads rows without changing them.

SELECT * FROM learners;

The star * means every column: name, city and age.

2. Choose rows with WHERE

WHERE keeps only rows that match a condition. Text values use single quotes; numbers do not need quotes.

SELECT name FROM learners WHERE city = 'Berlin';

This returns Alex and Sam. = means equal to.

SELECT name FROM learners WHERE age >= 18;

This also returns Alex and Sam. >= means greater than or equal to; < means less than; > means greater than.

SELECT name FROM learners WHERE age < 18;

This returns Mia. A semicolon ends each statement. Without ORDER BY, result order is not guaranteed; these examples focus on which rows match.
