# Subject icons

All icons are local SVG files; no font library, JavaScript package or remote request is needed at runtime.

- `sql.svg`: original database illustration created for this project.
- `python.svg`: Python original-color icon from [Devicon](https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg).
- `javascript.svg`: JavaScript original-color icon from [Devicon](https://github.com/devicons/devicon/blob/master/icons/javascript/javascript-original.svg).
- `sap.svg`: [Simple Icons SAP icon](https://github.com/simple-icons/simple-icons/blob/develop/icons/sap.svg), with the fill set to SAP blue (`#0FAAFF`).

Devicon artwork is distributed under the MIT license; its notice is retained in `LICENSE-Devicon.txt`. Simple Icons is distributed under CC0; its license is retained in `LICENSE-Simple-Icons.txt`. Logos identify the learning subjects and do not imply endorsement. Python's logo use information is available from the [Python Software Foundation](https://www.python.org/community/logos/).

The shared template presents every image at 32 by 32 pixels with empty alt text because the adjacent visible subject name supplies the accessible label. Subject names and lesson descriptions remain text, independent of the images.
